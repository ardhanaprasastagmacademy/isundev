# 1. PROJECT OVERVIEW

## 1.1 Nama Produk

**IsenDev**

IsenDev merupakan brand jasa pengembangan website yang berfokus pada pembuatan website untuk bisnis, UMKM, perusahaan, organisasi, maupun kebutuhan personal/profesional di Banyuwangi dan area sekitarnya.

Website IsenDev berfungsi sebagai:

1. Company profile.
2. Portfolio developer/agency.
3. Katalog layanan.
4. Media edukasi melalui artikel.
5. Landing page untuk menghasilkan calon klien.
6. Sumber informasi yang dapat dipahami Google Search dan sistem AI.
7. Identitas digital resmi IsenDev.

# 37. CANONICAL

Setiap halaman indexable memiliki self-referencing canonical.

Contoh:

```html
<link
  rel="canonical"
  href="https://DOMAIN-ISENDEV/tentang/"
>
```

Canonical harus menggunakan absolute URL.

Google menjelaskan bahwa `rel="canonical"` merupakan sinyal kuat, sementara sitemap juga membantu menunjukkan URL yang dipilih sebagai canonical.

---

### 3. Definition blocks

Contoh:

> **Apa itu website company profile?**
> Website company profile adalah website yang digunakan untuk memperkenalkan bisnis, layanan, profil perusahaan, portfolio, dan informasi kontak kepada calon pelanggan.

# 53. IMAGE SEO

Semua gambar harus:

* compressed;
* responsive;
* memiliki intrinsic dimensions;
* menggunakan descriptive filename;
* menggunakan alt text jika informatif;
* menggunakan `loading="lazy"` untuk image non-critical;
* tidak lazy-load hero/LCP image.

```text
isenDev-website-company-profile-banyuwangi.webp
```

bukan:

```text
IMG_29382.jpg
```

# 56. PERFORMANCE STRATEGY

## CSS

* minify;
* remove unused CSS;
* hindari stylesheet berlebihan;
* gunakan Bootstrap hanya sesuai kebutuhan;
* jangan memasukkan library CSS yang tidak digunakan.

## JavaScript

* gunakan vanilla JS jika memungkinkan;
* defer script non-critical;
* jangan menggunakan library animation besar tanpa kebutuhan;
* hindari JS untuk rendering konten utama.

## Images

* WebP/AVIF;
* responsive;
* lazy-load;
* explicit width/height.

## Fonts

* subset;
* preload critical font;
* font-display swap.

---

# 57. HERO PERFORMANCE

Hero image kemungkinan menjadi LCP element.

Maka:

**Jangan:**

```html
loading="lazy"
```

untuk hero image utama.

Gunakan:

```html
fetchpriority="high"
```

jika memang menjadi resource LCP yang sesuai.

Pastikan ukuran image tidak terlalu besar.

---

# 58. ANIMATION

Animasi harus:

* subtle;
* cepat;
* tidak blocking;
* tidak menyebabkan layout shift.

```css

opacity
```

sebisa mungkin.

Hindari animasi yang mengubah:

```text
width
height
top
left
margin
```

secara terus-menerus.
